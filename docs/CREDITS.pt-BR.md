# Créditos

[English](CREDITS.md) · Português (Brasil)

Este recomp não teria tradução, dublagem nem texturas em alta resolução sem o trabalho
das pessoas abaixo. O projeto só adapta esse trabalho para a versão Xbox; a autoria é
delas. Se você usa o PT-BR ou o pacote HD, visite as páginas originais e apoie os autores.

*Castlevania: Curse of Darkness* © Konami Digital Entertainment. Este projeto não é
afiliado à Konami nem aos autores citados.

## Tradução PT-BR (PS2)

Projeto idealizado e dirigido por **HNNEWGAMES**, com a Turma **STR Brasil**
(Sistema de Tradução Radical). Patch para a ISO europeia (SLES_537.55).

| Função | Autor |
|---|---|
| Administração, textos, vídeos e revisão | HNNEWGAMES |
| Gráficos (edição das texturas) | Mumm-ra (STR Brasil) |
| Ferramentas | ViT, Mumm-ra (STR Brasil) |

Agradecimento especial dos autores ao romhacker russo ViT, pelas ferramentas de edição
de texto.

Histórico publicado: 1.0 (01/12/2019), 2.0 (11/03/2020, correções de texto e gráficos),
2.1 (17/06/2020), 2.3.2 (24/01/2022, tradução).

## Pacote de texturas 4K

Por **PlatinumMimic** (platinummin no Buy Me a Coffee, **u/Calm-Consideration41** no
Reddit), feito para o PCSX2 sobre a versão americana do PS2 (SLUS-21168). As texturas
foram tratadas no chaiNNer para ficarem nítidas em resoluções altas sem mudar o estilo
artístico. O autor distribui o pacote de graça, como projeto pessoal, e aceita doações
opcionais. Ele também fez o pacote 4K de *Lament of Innocence*.

- Página do autor (download): <https://buymeacoffee.com/platinummin/castlevania-ps2-4k-texture-packs>
- Post no r/PCSX2: <https://www.reddit.com/r/PCSX2/comments/1sry8qk/castlevania_curse_of_darkness_4k_texture_pack/>
- Capturas de tela do autor: <https://imgur.com/a/bl8rsoJ>

## O que este projeto fez com esse material

- Converteu textos, imagens e áudio do patch PS2 para os formatos da versão Xbox, por
  scripts que rodam sobre as ISOs do próprio usuário (`tools/ps2_*.py`). Veja
  [TRANSLATION.pt-BR.md](TRANSLATION.pt-BR.md).
- Os arquivos do jogo, da tradução, da dublagem e do pacote HD não são distribuídos
  neste repositório.

Créditos levantados nas páginas acima em 25/10/2026. Se algum nome ou função estiver
errado ou faltando, abra uma issue para corrigir.
